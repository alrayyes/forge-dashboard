What this is

A read-only dashboard over repositories you already have access to on GitHub and/or a Forgejo instance. It doesn't modify anything on either forge on your behalf, and running your own instance means you're the one responsible for the credentials you give it and the host you run it on.

Third-party services

Every page here loads a stylesheet from fonts.googleapis.com. That's the only third-party request this app's own pages make — see the Privacy page for what that means and what else does or doesn't leave this app's own backend.
