What is standardized

Starting point: the Branches status group (StatusPills, #4237) already has glyphs and counts, and #4246 gives the pull request CI group the same ones. The shared pill generalizes that component. Size 32px, 13px type, one outline and one pressed fill, one visible label style, counts on both pages, the same bar and Filters sheet, the same Clear filters button. One component replaces the quick pill, the branches pill, the advisories filter button and the Insights radios, with forced-colours handling written once.

Not changed: the dropdowns for repository, author, label and dates, the title search, the checkbox, and the on, off and any segments.
